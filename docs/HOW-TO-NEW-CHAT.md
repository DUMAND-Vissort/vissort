# Как начинать новый чат с ассистентом

> Памятка для меня. Читать перед каждым новым чатом.
> Цель: за 1 минуту передать весь контекст проекта без потерь.

---

## Что нужно для нового чата

**Два компонента:**

1. **Промпт** — содержимое `docs/HANDOFF.md` (копируется целиком в первое сообщение).
2. **Файлы проекта** — только те, с которыми будем работать в этой сессии.

---

## Пошаговая инструкция

### Шаг 1. Открыть HANDOFF

```powershell
Get-Content D:\PROEKT\vissort\docs\HANDOFF.md | Set-Clipboard
```

Содержимое файла — в буфере обмена.

### Шаг 2. Открыть новый чат

Вставить промпт (Ctrl+V). Пока не отправлять.

### Шаг 3. Добавить строку с задачей

После промпта добавить:

```
Продолжаем работу. Актуальные задачи — в TODO.md.
Начинаем с [конкретная задача].
```

### Шаг 4. Приложить файлы

Кнопка attach → выбрать нужные файлы (см. таблицу ниже).

### Шаг 5. Отправить

Ассистент в контексте. Можно работать.

---

## Какие файлы прикладывать

**Зависит от задачи. Не прикладывать всё подряд.**

| Задача | Файлы |
|---|---|
| Плеер / камера / стимулы | `player-runtime.js`, `player.html` или `user.html` |
| Редактор сценариев | `admin.html`, `app.js` |
| База данных / sync | `data-layer.js`, `vissort-core.js`, нужные миграции |
| Edge Functions | `supabase/functions/*/index.ts`, нужные миграции |
| Service Worker / офлайн | `sw.js` |
| Голос / чтение | `voice.js`, `player-runtime.js` |
| Документация | сам `.md` + связанные `.md` |
| Общая сессия без цели | `docs/TODO.md`, `docs/VISION.md` |

**Если сомневаешься — приложи минимум.** Лучше меньше файлов, но точных.

---

## Что НЕ прикладывать

- Все файлы проекта (лишний шум, ~300 KB текста).
- `node_modules`, `.git`, `.env`, любые `.min.js`.
- Скриншоты без контекста.
- Файлы, которые не будем менять.

## Шаблон первого сообщения

```
[Содержимое docs/HANDOFF.md целиком]

---

Продолжаем работу. Актуальные задачи — в TODO.md (прилагаю).
Начинаем с [конкретная задача].

Файлы для работы: [список].
```

Затем — attach файлов.

---

## Что делать в конце сессии

**Перед закрытием чата:**

1. **Обновить HANDOFF.md.**
   - Раздел «Текущее состояние» — что работает, что нет.
   - Раздел «Последние изменения» — что сделали сегодня.
   - Раздел «Коммиты» — добавить новые хеши.
   - Раздел «Приоритеты» — если поменялись.

2. **Обновить TODO.md.**
   - Отметить сделанное `[x]`.
   - Добавить новые задачи.
   - Убрать устаревшее.

3. **Закоммитить.**

```powershell
cd D:\PROEKT\vissort
git add docs/HANDOFF.md docs/TODO.md
git commit -m "docs: update handoff + todo after session"
git push
```

Тогда к следующей сессии HANDOFF актуален.

## Шорткат для скорости

Сделай в PowerShell функцию (в профиле `$PROFILE`):

```powershell
function Get-Handoff {
    Get-Content D:\PROEKT\vissort\docs\HANDOFF.md | Set-Clipboard
    Write-Host "HANDOFF скопирован в буфер" -ForegroundColor Green
}
Set-Alias handoff Get-Handoff
```

Теперь достаточно набрать `handoff` в PowerShell — и промпт в буфере.

**Проверка:** сохранить профиль, открыть новый PowerShell, набрать `handoff`.

## Типичные ошибки

**Приложил все файлы проекта.**
→ Шум в контексте. Ассистент тратит внимание на лишнее. Прикладывай только нужное.

**Забыл обновить HANDOFF после прошлой сессии.**
→ Новый чат работает со старым контекстом. Через месяц это станет проблемой.

**Пересказал контекст своими словами вместо HANDOFF.**
→ Потерялись детали. Всегда используй HANDOFF как есть.

**Скопировал не весь HANDOFF, а часть.**
→ Ассистент не в полном контексте. Копируй целиком.

**Начал новый чат без задачи.**
→ Ассистент не знает, с чего начать. Всегда указывай конкретную задачу.
