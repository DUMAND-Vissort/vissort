## 10. Топ-10 критичных задач

1. **Playwright + CI** — без тестов нельзя рефакторить
2. **Юрлицо + расчётный счёт** — без этого не принять оплату
3. **Лендинг** — без него некуда вести трафик
4. **Демо-видео 90 сек** — без него не показать продукт
5. **Библиотека методик** — без неё нечего назначить врачу
6. **Интерфейс врача** — без него нет B2B
7. **Пилот с 1 клиникой** — без него нет доказательной базы
8. **README + ARCHITECTURE** — без них не привлечь команду
9. **Telegram-канал** — без него нет органики
10. **Бэкап БД** — без него можно потерять всё
