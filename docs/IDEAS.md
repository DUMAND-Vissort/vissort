# Vissort — Идеи и классификации для разработки

> Этот файл содержит медицинские и технические идеи, которые еще не внедрены в код, но запланированы. Сюда же пишем классификации для будущих тренажеров.

---

## 1. Классификации аккомодации (для дозирования нагрузки)

### По типу стимула (природа сигнала):
*   **Рефлекторная аккомодация.** Ответ на размытие (retinal blur). Основной инструмент: даём размытие в дптр, система компенсирует.
*   **Вергентная (конвергентная) аккомодация.** Запускается сдвигом изображений (диспаратностью). Глаз "подтягивает" фокус за сведением осей (АК/А).
*   **Проксимальная аккомодация.** Реакция на осознанное восприятие близости (size cues, параллакс, перспектива). Имитируется масштабированием или анимацией "приближения".
*   **Тоническая аккомодация.** Базовый уровень напряжения цилиарной мышцы (зона покоя). Тренировка — удержание нейтрального уровня без дрейфа в спазм.

### По динамике изменения:
*   **Статическая.** Удержание фокуса на одной дистанции (для устойчивости и снятия ПИНА).
*   **Динамическая.** Переключение между дистанциями ("раскачки") — для объёма и скорости.
*   **Флуктуирующая.** Поддержание фокуса при небольших колебаниях размытия (устойчивость к утомлению).

### По характеру ответа:
*   **Фазическая.** Быстрая стартовая реакция (~300–400 мс). Упражнение "поймай старт".
*   **Тоническая (поддерживающая).** Длительное удержание. Упражнение "удержи 30 секунд".

## 2. Классификации конвергенции/дивергенции (бинокулярные упражнения)

### По типу фузии:
*   **Сенсорная фузия.** Способность слить два изображения (даже если фокус не идеален).
*   **Моторная фузия.** Активное сведение/разведение глаз для устранения двоения.

### По направлению:
*   **Конвергенция (сведение).**
*   **Дивергенция (разведение).** Часто слабее, требует отдельной тренировки в связке с аккомодацией.

### По наличию конфликта:
*   **Согласованная работа (АК/А в норме).**
*   **Конфликт вергенции и аккомодации.** (На ранних этапах — избегать, использовать для тренировки резервов).

---

## 3. Классификации утомления (для адаптации сложности)

*   **Аккомодационное утомление.** Падает запас аккомодации, растёт латентность, "плывёт" чёткость.
*   **Фузионное утомление.** Нарушается слияние, появляется двоение.
*   **Комбинированное утомление.** Страдают оба компонента (чаще у офисных работников).
*   **Световое/контрастное утомление.** Дискомфорт от яркости, снижение контрастной чувствительности.

**Как использовать:** Профили "аккомодационный тип", "фузионный тип", "комбинированный тип" — для подбора упражнений.

## 4. Практические слои для интерфейса Vissort

| Уровень | Что классифицирует | Как использовать |
| :--- | :--- | :--- |
| **Тип тренировки** | Снятие спазма / Расширение зоны покоя / Скорость / Устойчивость | Выбор пользователем или назначение системой. |
| **Доминирующий стимул** | Размытие / Сдвиг / Спектральный состав / Контраст | Определяет основной коэффициент (w_A, w_C, w_P). |
| **Режим сложности** | Лёгкий / Средний / Продвинутый | Управляет амплитудой изменений (дптр, угловые минуты). |
| **Состояние** | Без утомления / Лёгкое / Выраженное | Автоматическое снижение сложности по метрикам (время реакции, двоение). |

## 5. Реализация через коэффициенты (w_A, w_C, w_P)

Примеры сценариев:
*   **"Снятие ПИНА":** тип — тоническая аккомодация; стимул — спектральный (тёплые тона) + мин. размытие; режим — лёгкий; состояние — без утомления.
*   **"Скорость":** тип — динамическая аккомодация; стимул — размытие + сдвиг; режим — средний; состояние — лёгкое утомление (короткие серии).

*Идея: коэффициенты — это "математика" для реализации упражнений, классификация — "словарь" для их описания.*
