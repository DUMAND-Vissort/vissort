## Стратегия

**Приоритет 1** — частные кабинеты, оптометристы, ортоптисты.
Быстрое решение, готовая аудитория (дети с амблиопией), низкий порог входа.

**Приоритет 2** — мелкие и средние коммерческие клиники.
Поток пациентов, но решение дольше (1–2 месяца).

**Приоритет 3** — сети и крупные центры.
Якорные клиенты, долгий цикл, нужны кейсы.

**Не трогаем на старте** — федеральные (44-ФЗ, медизделие, 12–24 месяца).

## План работы

### Шаг 1. Подготовка (1–2 недели)

- [ ] Презентация на 1 страницу
- [ ] Демо-видео 2 минуты
- [ ] Текст письма для холодного контакта
- [ ] Скрипт звонка

### Шаг 2. Пилот (2–3 месяца)

- [ ] Выбрать 3 клиники (Ясный Взор, Счастливый взгляд, Глазка)
- [ ] Пилот: 10 пациентов, 2 месяца, взамен — данные и отзыв
- [ ] Договор на пилот — упрощённый
- [ ] Обучение врача (2 часа, удалённо)

### Шаг 3. По результатам

- [ ] Метрики: adherence, динамика V, отзывы
- [ ] Публикация кейса
- [ ] Коммерческое предложение клинике
- [ ] Следующие 5 клиник — с кейсом

### Шаг 4. Масштабирование (год 2)

- [ ] 20–50 клиник
- [ ] Партнёрская программа для врачей
- [ ] Выступление на конференции «Ясного Взора»
