# Vissort — возможности редактора методик

> Приложение к PITCH.md. Для врачей и методистов, которые хотят понять глубину платформы.
> Не для пациента. Не для маркетинга. Только для тех, кто будет собирать сценарии.

---

## Что такое редактор методик

Редактор — это визуальный конструктор, в котором методист или врач собирает протокол тренировки как граф: узлы + связи между ними. Всё, что делает пациент дома, описано этим графом.

Врач-клиницист обычно работает с готовыми методиками из библиотеки. Редактор открывается, если нужна своя методика, или если нужно адаптировать существующую под конкретный случай.

---

## 1. Типы узлов

Пять типов узлов, покрывающих все тренировочные сценарии.

### 1.1. Узел «Стимул»

Основной узел для тренировки остроты зрения. Показывает один optotype за раз.

**Что настраивается:**

- **Форма стимула:**
  - Буква Е (знак Сивцева) — классика для детей
  - Кольцо Ландольта — разрыв в одну из четырёх сторон
  - Круг — двухслойный радиальный градиент с независимой анимацией слоёв

- **Острота зрения (V):**
  - Стартовая V: 0.1 – 1.0
  - Целевая V: 0.1 – 1.0
  - Шаг V: 0.05 / 0.1 / 0.2 / 0.5
  - Адаптивность: ручная или по сериям (при успехе — рост, при провале — снижение)

- **Дистанция:**
  - 0.1 – 20 м, шаг 0.1 м
  - Влияет на физический размер стимула в мм и пикселях

- **PPI экрана:**
  - Автоматически или вручную
  - Калибровка под конкретный монитор

- **Цвета:**
  - Цвет стимула (RGB)
  - Цвет фона (RGB)

- **Серии:**
  - Количество циклов в серии: 1 – 20
  - Критерий правильности серии: 1 – 20 ответов
  - Всего серий в узле: 1 – 50

- **Сетка положения:**
  - Столбцов (X): 1 – 10
  - Строк (Y): 1 – 10
  - Показывать линии сетки: да / нет
  - Случайная клетка: да / нет
  - Избегать повтора: да / нет
  - Активные клетки — подмножество (например, только 4 из 9)

- **Случайное положение:**
  - Стимул появляется в произвольной точке экрана
  - Полезно для периферического тренинга

### 1.2. Узел «Динамика»

Плавная смена цвета стимула или фона с заданной скоростью.

**Что настраивается:**

- **Динамика стимула:**
  - Цвет 1 (начальный) — RGB
  - Цвет 3 (промежуточный, опционально) — RGB
  - Цвет 2 (конечный) — RGB
  - Время полного цикла: от 0.2 с
  - Повторять цикл: да / нет
  - Пинг-понг (A→B→A): да / нет

- **Динамика фона:**
  - Те же параметры, но для фона

- **Физиологический режим:**
  - Палитра из 17 точек от глубокого красного (0.0 дптр) до фиолетового (+1.6 дптр)
  - Шаг: 0.1 – 1.6 дптр
  - Длительность шага: от 0.1 с
  - Подпись текущего дптр: да / нет

### 1.3. Узел «Чтение»

Тренировка чтения с адаптивным шрифтом. Ключевой узел для работы с реальными книгами.

**Что настраивается:**

- **Книга:**
  - Формат: TXT / FB2 / EPUB
  - Загрузка из файла
  - Выбор из ранее загруженных
  - Закладка (сохранение позиции)

- **Шрифт:**
  - Сивцев (специальный медицинский)
  - Любой системный
  - Загрузка своего файла шрифта
  - Список всех системных через Local Fonts API

- **Острота зрения:**
  - V: 0.1 – 1.0
  - Дистанция: 0.1 – 20 м
  - Расчёт размера через формулу остроты

- **Цвет текста:**
  - Любой RGB

- **Фон, 4 режима:**
  - **Сплошной** — один цвет
  - **Две половины** — резкая граница L/R, отдельные цвета для каждой стороны
  - **Градиент** — 2 или 3 цвета, настраиваемая позиция середины
  - **Динамический** — плавная смена, отдельный выбор режима (простой / RGB / физиологический)

- **Динамический фон:**
  - Начальный цвет, конечный цвет, опционально промежуточный
  - Время цикла: от 0.2 с
  - Повтор, пинг-понг
  - Физиологический режим с шагом 0.1 – 1.6 дптр

- **Длительность:**
  - Время показа: 0 = до кнопки, или явное значение
  - Автосохранение закладки: да / нет

### 1.4. Узел «Сравнение»

Тренировка пространственного различения и поиска.

**Два подрежима:**

- **Сравнение направлений** — пациент видит две клетки, отвечает «Да» (одинаковые) / «Нет» (разные)
- **Найти одинаковые** — на сетке несколько пар, пациент кликает пару с одинаковым направлением

**Что настраивается:**

- **Сетка:**
  - Столбцов (X): 2 – 6
  - Строк (Y): 1 – 6
  - Активные клетки — выбрать вручную (минимум 2)

- **Параметры каждой клетки:**
  - V: 0.1 – 1.0
  - Цвет стимула
  - Цвет фона
  - Время показа: 200 – 5000 мс
  - Дистанция и PPI наследуются из узла

- **Серии:**
  - Количество циклов: 1 – 20
  - Порог правильности

### 1.5. Узел «Логика»

Условные переходы. Зарезервирован, пока не влияет на граф. В планах — переходы по критериям: «если V растёт — к чтению, если падает — вернуться к стимулу».

## 2. Дополнительные модули в узле «Стимул»

Помимо базовых настроек, узел «Стимул» содержит несколько независимых модулей, которые можно включать одновременно.

### 2.1. Периферийные точки

Дополнительные стимулы на границе поля зрения.

- Количество точек: 1 – 12
- Острота (V): 0.1 – 1.0 — размер периферийной точки
- Радиус min / max: 20 – 100 % — граница, за которой появляются точки
- Цвет точки — RGB
- Движение:
  - **Статично**
  - **Вращение** — точки движутся по кругу
  - **Пульс** — точки колеблются по размеру
- Скорость: 0.02 – 5 (об/с или Гц)
- Случайные углы: да / нет

### 2.2. Цифровой дефокус

Имитация периферического зрения. В центре — чёрный стимул на красном фоне, периферия — синяя с размытием.

- Радиус центра: 3 – 50 мм
- Фон центра: RGB (обычно красный)
- Цвет стимула: RGB (обычно чёрный)
- Фон периферии: RGB (обычно синий)
- Размытие к краю: 0 – 100 %

### 2.3. Динамика Круг

Двухслойный радиальный градиент с независимыми анимациями.

**Внутренний диск:**
- Показывать: да / нет
- Радиус: 5 – 95 % от общего
- Цвет 1 (центр), Цвет 3 (середина, опционально), Цвет 2 (край)
- Время цикла: от 0.2 с
- Повторять: да / нет
- Пинг-понг: да / нет

**Внешнее кольцо:**
- Те же параметры, независимые от внутреннего
- Цвет 1 (у диска), Цвет 3 (опционально), Цвет 2 (край)
- Время цикла, повтор, пинг-понг

### 2.4. Моргание

Резкая смена цвета без плавного перехода — в отличие от «Динамики». Тренирует быстрое восприятие.

- Цель: только стимул / только фон / стимул + фон
- Цвет A — RGB
- Цвет B — RGB
- Период: 50 – 5000 мс
- Доля A: 0.05 – 0.95
- Количество морганий: 0 = бесконечно

### 2.5. Сетка положения

Уже описана в узле «Стимул». Может быть и как самостоятельная механика (без случайного положения) — стимул всегда появляется в одной конкретной клетке.

## 3. Связи между узлами

Узлы связываются двумя типами линий.

### 3.1. Обычная связь

Переход от одного узла к другому. Один раз, дальше — по графу.

**Наследование параметров:**
- **Острота зрения (размер):** следующий узел берёт V предыдущего как стартовую
- **Скорость:** следующий узел берёт duration предыдущего

Наследование удобно, когда нужно построить цепочку: «стимул с V=0.3 → ещё один с той же V → ещё один, но с V=0.5».

### 3.2. Петля

Возврат к узлу N раз. Используется для повторов.

**Параметры петли:**
- Количество циклов: 1 – 9999
- Инициировать по ответу: да / нет

Пример: «стимул → пауза → вернуться к стимулу 5 раз». В графе это одна пунктирная петля вместо 5 узлов.

### 3.3. Стартовый узел

Первый узел в графе. Отмечается чек-боксом в шапке. От него строится очередь проигрывания.

## 4. Заготовки (templates)

Готовые узлы и группы узлов, которые можно переиспользовать.

- **Сохранить узел как заготовку** — кнопка на узле
- **Импорт заготовок из папки** — загрузка группы сценариев
- **Экспорт всех заготовок** — выгрузка в JSON
- **Применение заготовки** — добавление на холст

Применение: врач настраивает узел один раз и использует в 20 методиках. Экономит время.

## 5. Инспектор

Боковая панель для тонкой настройки выбранного узла. Открывается двойным кликом по узлу.

**Разделы инспектора:**

- **Информация** — название узла, тип стимула, активность
- **Острота зрения** — V, шаг, дистанция, PPI, предпросмотр размера в мм и px
- **Серии** — размер серии, порог, адаптивность
- **Цвета** — стимул, фон
- **Случайность** — случайное положение
- **Сетка** — все параметры сетки + превью активных клеток
- **Динамика Круг** — внутренний круг + внешнее кольцо
- **Периферийные точки** — включение, количество, движение
- **Цифровой дефокус** — радиус, цвета, размытие
- **Моргание** — цель, цвета, период
- **Цикл показа** — задержки и время показа с выбором единиц (мс / с / мин)
- **Динамика буквы** — плавная смена цвета стимула
- **Динамика фона** — плавная смена цвета фона

Все параметры сохраняются в узле и уходят в сценарий.

## 6. Что нового в редакторе (в сравнении с аналогами)

**По сравнению с игровыми приложениями:**
- Игра — это фиксированная механика. Редактор — это язык для описания любой механики.
- Игра — это чёрный ящик. Редактор — это граф, который можно показать врачу и коллеге.

**По сравнению с другими «конструкторами»:**
- Большинство конструкторов ограничены одной механикой (например, только адаптивная острота).
- Vissort объединяет пять типов узлов и шесть независимых модулей — можно собрать всё от простой тренировки до сложного протокола с периферией, дефокусом и морганием.

**По сравнению с таблицами Сивцева:**
- Таблица — статична. Редактор — динамичен: узлы меняются, V растёт, цвет плавает.
- Таблица — не воспроизводима на другом экране. Редактор — калибруется через PPI.

## 7. Что можно собрать в редакторе

Примеры методик, которые сейчас возможны:

1. **Классическая тренировка остроты** — стимул с V от 0.3 к 0.8, серии 6×10, порог 4.
2. **Аккомодационная тренировка** — динамика фона физиологическая, чтение между стимулами.
3. **Периферическая тренировка** — стимул + 6 вращающихся точек по кругу.
4. **Дефокусная стимуляция** — красный центр, синяя периферия, чёрный стимул.
5. **Моргание с тренировкой внимания** — резкая смена цветов каждые 500 мс.
6. **Амблиопия по Кемпбеллу** — V на пороге, контрастные задачи, обратная связь.
7. **Спазм аккомодации** — длительные сессии чтения с плавной сменой фона.
8. **Комбинированная тренировка** — стимул + сравнение + чтение в одном графе.

## 8. Что в разработке

- **Логические переходы** — if/then между узлами
- **Шаблоны методик** — библиотека готовых графов
- **Версионирование** — методика + версия в графе
- **Импорт/экспорт методик** — обмен между клиниками
- **Комментарии в графе** — подсказки для коллег
- **Автопроверка сценария** — валидация перед запуском
