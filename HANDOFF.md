## 🚨 Грабли (не наступить)

1. **`hideExtraInspectorBlocks()` (`app.js:1909`)** скрывает секцию с заголовком «Цвета». Сейчас **закомментирована**. Если включить — пропадут цвета и яркость.
2. **Два id для ЖС:** новый `dyn-enabled`; старый обработчик `inp-dyn-enabled` (`app.js:1872-1906`) — мёртвый код (безвреден, но не путать).
3. **Кодировка:** файлы с CRLF/LF вперемешку. Не пересохранять целиком; кириллицу, участвующую в сравнениях, писать `\u`-эскейпами.
4. **Не трогать** ветвление в `app-editor.js` / `app-player.js` — работает.
5. PowerShell-скрипты с регулярками по JS-файлам **ломали** файлы — править через git/редактор, а не `-replace`.
6. **`parseInt(x) || 100`** — классическая ловушка: `parseInt('0') || 100` = 100, нулевая яркость терялась. Правильно: `Number.isFinite(n) ? n : 100`. Уже исправлено в `app-inspector.js`; не возвращать.
7. **Чёрный стимул:** `node.stimR || 255` превращает 0 в 255. Только `!= null`. Исправлено в `app-player.js:175-177`.
8. **Тест `editor.spec.js` «переключение режима»** помечен `test.skip` — кнопка `#btn-mode-toggle` закомментирована в `admin.html`. Не «чинить» тест, пока режим не вернут.
9. **`dyn.active !== false` — ловушка «ЖС включён по умолчанию».** Для узла без ЖС `dyn.active` = `undefined`, `undefined !== false` → true → чекбокс «Живой стимул активен» отрисован отмеченным, «Применить» писал `active: true`, и плеер уходил в динамический путь. Там D = 0 маппится в `colorTable[0]` = `rgb(255,0,0)` (vissort-core.js:503) и **стимул, и фон** → экран целиком красный, буквы не видно. Правильно: `dyn.active === true` (исправлено в `app-inspector.js:118-123` и `app-stimulus-editor.js:101`). Регрессия закрыта тестом `tests/dyn-toggle.spec.js`.
10. **Три палитры для одного D (исправлено).** Диоптрия — оптическая сила, а не «затухание контраста»: D привязано к длине волны (продольная хроматическая аберрация, LCA). Раньше цвета жили в трёх местах: `colorTable` в ядре («радуга»), жёсткая таблица в `app-generator.js` и её копия в `player-reading.js`; плюс была попытка (коммит `9cb48b4`) вообще убрать `colorTable` из плеера и красить ЖС цветами узла — тогда «2.0 D = синий» потерялось. Теперь единственный источник — `VissortCore.PHYSIO_SCALE` (редуцированный глаз Emsley + дисперсия Коши, калибровка CDR(670→400 нм) = 2.4 дптр): **0.0 D = 670 нм (красный), 2.0 D = 423 нм (сине-фиолетовый)**. Не заводить локальных копий палитры (исключение — автономный `sandbox.html`/`sandbox.js`, он не грузит ядро), не возвращать «дефокус-затухание» и не подменять оттенок цветом узла при активном ЖС. Регрессия — `tests/dyn-colors.spec.js` (6 кейсов).
