# Vissort — Идеи и классификации для разработки

> Этот файл содержит медицинские и технические идеи, которые еще не внедрены в код, но запланированы.

---

## 1. Классификации аккомодации (для дозирования нагрузки)

### По типу стимула (природа сигнала):
- **Рефлекторная аккомодация.** Ответ на размытие (retinal blur).
- **Вергентная (конвергентная) аккомодация.** Запускается сдвигом изображений (диспаратностью).
- **Проксимальная аккомодация.** Реакция на осознанное восприятие близости.
- **Тоническая аккомодация.** Базовый уровень напряжения цилиарной мышцы.

### По динамике изменения:
- **Статическая.** Удержание фокуса на одной дистанции.
- **Динамическая.** Переключение между дистанциями ("раскачки").
- **Флуктуирующая.** Поддержание фокуса при небольших колебаниях размытия.

### По характеру ответа:
- **Фазическая.** Быстрая стартовая реакция (~300–400 мс).
- **Тоническая (поддерживающая).** Длительное удержание.

## 2. Классификации конвергенции/дивергенции

### По типу фузии:
- **Сенсорная фузия.** Способность слить два изображения.
- **Моторная фузия.** Активное сведение/разведение глаз для устранения двоения.

### По направлению:
- **Конвергенция (сведение).**
- **Дивергенция (разведение).**

### По наличию конфликта:
- **Согласованная работа (АК/А в норме).**
- **Конфликт вергенции и аккомодации.**

---

## 3. Классификации утомления (для адаптации сложности)

- **Аккомодационное утомление.** Падает запас аккомодации.
- **Фузионное утомление.** Нарушается слияние.
- **Комбинированное утомление.** Страдают оба компонента.
- **Световое/контрастное утомление.** Дискомфорт от яркости.

---

## 4. Практические слои для интерфейса Vissort

| Уровень | Что классифицирует | Как использовать |
| :--- | :--- | :--- |
| **Тип тренировки** | Снятие спазма / Расширение зоны покоя / Скорость / Устойчивость | Выбор пользователем. |
| **Доминирующий стимул** | Размытие / Сдвиг / Спектральный состав / Контраст | Определяет основной коэффициент. |
| **Режим сложности** | Лёгкий / Средний / Продвинутый | Управляет амплитудой изменений. |
| **Состояние** | Без утомления / Лёгкое / Выраженное | Автоматическое снижение сложности. |

---

## 5. Реализация через коэффициенты (w_A, w_C, w_P)

Примеры сценариев:
- **"Снятие ПИНА":** тип — тоническая аккомодация; стимул — спектральный.
- **"Скорость":** тип — динамическая аккомодация; стимул — размытие + сдвиг.

*Идея: коэффициенты — это "математика" для реализации упражнений, классификация — "словарь" для их описания.*
